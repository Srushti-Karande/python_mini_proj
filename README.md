# Grade Calculator Using Conditional Constructs

Python mini project (SY-C / Semester III) by Vedika Bodke and Srushti Karande.

The program takes marks in five subjects, calculates the total and percentage,
and assigns a grade using `if`, `elif` and `else`.

## Run

    python miniproject.py

## Grading scale

| Grade | Percentage |
|-------|------------|
| A+    | 90 and above |
| A     | 80 - 89 |
| B     | 70 - 79 |
| C     | 60 - 69 |
| D     | 35 - 59 |
| F     | Below 35 |

The full project report is in `Python_Report_Mini_Project_Redesigned.docx`.
